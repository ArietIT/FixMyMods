# FixMyMods — мой проект

**Проект:** FixMyMods — диагностика ошибок Minecraft.

**Технологии:** Python + PySide6.

**Платформы:** Windows, Linux (Ubuntu и Arch Linux), macOS.

**Цель:** создать desktop-приложение, которое анализирует `latest.log` и crash-report, обнаруживает распространённые ошибки модов и объясняет, как их исправить.
